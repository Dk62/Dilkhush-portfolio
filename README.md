# Dilkhush Portfolio

This is a portfolio website built with JavaScript, CSS, and HTML to showcase projects, skills, and professional information.

## 📋 Description

A modern and responsive portfolio website designed to highlight personal projects, technical skills, and professional experience.

## 🛠️ Tech Stack

- **JavaScript**: 96.8% - Core functionality and interactivity
- **CSS**: 2.9% - Styling and responsive design
- **HTML**: 0.3% - Structure and markup

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Interactive project showcase
- Smooth animations and transitions
- Contact information and social media links
- Clean and modern UI


## 🔧 Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/Dk62/Dilkhush-portfolio.git
```

2. Navigate to the project directory:
```bash
cd Dilkhush-portfolio
```

3. Open `index.html` in your web browser or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (if http-server is installed)
http-server
```

## 🌐 Usage

Simply open the portfolio website in your browser to view the projects and information. Navigate through different sections to explore the portfolio.
